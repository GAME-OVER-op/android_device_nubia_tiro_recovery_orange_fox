The supplied kernel tree contains:
  arch/arm64/configs/oem/boards/tiro_diff.config
  CONFIG_ZTE_BOARD_NAME="tiro"

The Tiro runtime log shows Nubia's haptic_hv stack (`haptic.ko`) registering an
input device named "awinic_haptic" and selecting the AW8692x implementation.
The same driver exposes a timed-output sysfs group including `cont`. Its
continuous-mode handler does not require `ram_init`, while FF_CONSTANT maps to
AW_RAM_LOOP_MODE. Recovery therefore targets the native `cont` node first and
uses input FF only as fallback.

The flashable recovery.img does NOT contain a kernel payload. Therefore this
project deliberately does not rebuild or embed the Lineage kernel. This avoids
mixing a recovery userspace with a kernel that may not match the user's current
vendor_boot/module ABI.
